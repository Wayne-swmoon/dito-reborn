# 홈페이지 템플릿 보관함

배포 후 주소: `/templates/` (예: https://dito-reborn7.pages.dev/templates/)

| 폴더 | 이름 | 특징 |
|---|---|---|
| `template-1/` | 트러스트 블루 | 네이비·블루·주황, 사무장 인물 컷아웃 첫 화면, 계단식 진행 절차 |
| `template-2/` | 민트 크림 | Figma 민트 프레시 × 실트스톤 팔레트, 첫 화면 사례 영상 |
| `template-3/` | 모션 릴 (비교용) | 현재 메인 사이트와 같은 디자인 + 테마색 고르기 |

- 각 폴더의 `index.html` 하나에 글꼴·사진·로고가 들어 있습니다. 영상은 사이트 공용 `/media/` 폴더를 씁니다.
- 검색엔진에 노출되지 않도록 `noindex`가 들어 있습니다.
- 템플릿 1·2의 상담 폼(본문 폼, 하단 고정 바)은 메인과 같은 접수 코드(`window.rebornSubmit`, 메일 발송 + Firebase 저장)에 연결되어 있어 바로 쓸 수 있습니다.
- 템플릿 1·2를 메인으로 바꾸려면: 해당 폴더의 `index.html`을 루트 `index.html` 자리로 옮기고, `<head>`의 `noindex`를 지운 뒤 메인 검색·공유 메타 태그(제목, 설명, og:image, GA 태그)를 옮겨 붙이면 됩니다.
